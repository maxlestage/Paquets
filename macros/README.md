# paquets-macros

Attribute macros of [Paquets](https://maxlestage.github.io/Paquets/), the simplest
full-stack web framework for Rust. Depend on `paquets`, which re-exports them:

```rust
use paquets::prelude::*;

#[model]                // a database table, JSON in and out
struct Todo {
    id: i64,            // primary key, generated by the database
    title: String,
    done: bool,
}

#[data]                 // plain JSON data (forms, API payloads)
struct Login {
    email: String,
    password: String,
}
```
