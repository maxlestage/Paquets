# FAQ

Short answers to common questions, with links to the pages that go further.

## About Paquets

### What is Paquets, in one sentence?

A Rust framework that gives you, with one crate and one `App`, a fast server, security in front of every request, a database with typed queries, REST APIs, server-rendered pages with complete SEO tags, and interactive WebAssembly islands. See the [Introduction](introduction.md).

### Is it ready for production?

Paquets is young (version 0.1). It is built on four packages that are tested on their own (Vitesse, Securite, memoire-orm, Active), and its defaults are made for production: security shield, graceful shutdown, a database from `DATABASE_URL`, release builds in the `Dockerfile`. But its API may still change between 0.x versions, and it doesn't have years of use behind it. Try it on a project where you can follow its evolution, and read the limits in the [Introduction](introduction.md#what-paquets-doesnt-do-yet).

### Why not axum, actix-web or Leptos?

They are excellent, larger projects. Paquets makes other trade-offs:

- **Everything in one place.** Server, security, database, pages and islands work together without choosing and wiring a dozen crates.
- **Secure by default.** Firewall, rate limit, CSRF protection and security headers are on before you write any code.
- **No macros in views, no extractors in handlers.** A handler takes a `Request` and returns a response; a view is a chain of function calls. rust-analyzer and the compiler understand everything.
- **Fast.** Its server outperforms actix-web and axum in its benchmarks (see [Performance](performance.md)).

Choose a larger framework if you need its ecosystem, server functions, or a team that already knows it.

### Do I need to know Rust well?

No. Most handlers are a few lines long, and this documentation explains the Rust-specific parts as they come up (`async move`, `?`, `Option`). Knowing the basics of the language (the first chapters of [the Rust book](https://doc.rust-lang.org/book/)) helps a lot.

### Do I need to write JavaScript?

No for pages, APIs and islands: everything is Rust, including the interactive parts. The browser receives a small JavaScript loader generated by `wasm-bindgen`, which you never write or edit. For a browser client of a WebSocket, a small script is the simplest option (see [WebSocket](websocket.md#connecting-from-a-page)).

### Is it free?

Paquets is free to use as a dependency, commercial projects included (it is proprietary software: see [Which license?](#which-license)). Hosting is another matter: Heroku has no free plan (an Eco dyno costs about $5 a month, see [Deploy to Heroku](deploy-heroku-mobile.md)). The Docker image runs on any host, including your own server.

## Writing code

### Why does `main().child(...)` fail with "no method named child found for enum Result"?

In a file that defines `fn main` (usually `src/main.rs`), the name `main` is your program's function, which hides the `main()` HTML tag. Write `html::main()` in that file. Everywhere else, `main()` works. See [Pages](pages.md#the-main-tag-in-mainrs).

### Why does the compiler say "future cannot be sent between threads safely"?

A handler's future must be able to move between threads, and two things prevent it:

- a **view** (`div()`, `Page`…) created before an `.await`: build the page after the last `.await` (see [Pages](pages.md#build-the-page-at-the-end-of-the-handler));
- a `std::sync::Mutex` or `RwLock` guard kept across an `.await`: read the body or the database first, then take the lock, or use `tokio::sync::Mutex`.

### How do I change the format of every error?

With `app.on_error(|err: Error| ...)`: it receives a `paquets::Error` and returns any response. Set the status yourself with `res::status(err.status())`. See [Errors](errors.md#changing-the-format-of-every-error).

### How do I share data between requests?

For data that must last, use the [database](database.md). For settings, caches and counters that live as long as the server, use `app.state(value)` and `req.state::<T>()` (see [Configuration](configuration.md#shared-state)).

### How do I get the client's IP address?

`req.extensions().get::<paquets::securite::ClientIp>()` returns the address found by the shield, which is correct behind Heroku's router. See [Requests and responses](requests-responses.md#the-clients-ip-address).

### How do I log users in?

Paquets doesn't include user accounts. Depending on your needs: a shared token for an API, Securite's `Auth` guard for an admin section, or sessions stored in your database. See [Security](security.md#authentication).

### Can components be async?

No: components are plain functions that build a view. Do the asynchronous work (database, HTTP calls) in the handler first, then build the page with the results.

### Can an island call my API?

Yes, with the browser's `fetch` through the `web-sys` and `wasm-bindgen-futures` crates (see [Active's events guide](https://maxlestage.github.io/Active/en/docs/events/)). An island can also contain a plain HTML form that posts to one of your routes.

### Is there hot reload?

Not built in. `paquets dev` builds and runs the app once; after a change, stop it and run it again. A file watcher automates this: `cargo watch -s "paquets dev"` (install it with `cargo install cargo-watch`).

## Database

### Which database should I use?

In memory while you learn and in tests, SQLite for a single server with a persistent disk, PostgreSQL on Heroku or with several servers. See [Database](database.md#which-database-should-i-use).

### Why did my data disappear?

Without `DATABASE_URL`, the database is in memory and is emptied when the server stops. On Heroku, SQLite files are erased at every restart too. Use PostgreSQL (the Heroku Postgres add-on) for data that must last.

### I added a field to a model, and now I get 500 errors.

Tables are created when they are missing, never changed: the existing table doesn't have the new column. Add a migration. See [Database](database.md#changing-a-table-later).

### How do I see the SQL of a query?

`Todo::query().filter(Todo::DONE.eq(false)).to_sql(paquets::orm::Dialect::Postgres)` returns it as a string, without running it.

## Security

### Why do I get 403 Forbidden?

The shield blocked the request: the response's `code` field says why (`waf_blocked`, `csrf_rejected`, `bot_blocked`…). A cross-site form, an attack pattern in the URL or an attack tool's user agent are refused before your code runs. See [Security](security.md#what-a-blocked-request-looks-like).

### Why do I get 429 Too Many Requests?

The rate limit allows 20 requests per second per IP address, with bursts of 100. Three common cases:

- **in tests**, all requests come from the same client: remove the rate limit in tests that send many requests (see [Testing](testing.md#testing-security));
- **in a load test**: the same, see [Performance](performance.md#measuring);
- **behind a proxy** other than Heroku's, all visitors share the proxy's address: tell the shield where the real address is (see [Security](security.md#the-client-ip-behind-a-proxy)).

### My page can't load a font or a script from another site.

The page's Content-Security-Policy only allows your own files. Download the font or the script into `public/` (better for speed and privacy), or add the source to the page's policy. See [Pages](pages.md#the-content-security-policy).

### Is HTTPS supported? HTTP/2?

The server speaks HTTP/1.1 (and HTTP/3 with the `http3` feature), without TLS. HTTPS and HTTP/2 come from what is in front of it: Heroku's router, a reverse proxy (Caddy, Nginx) or a CDN. The shield then keeps browsers on HTTPS with the `Strict-Transport-Security` header.

### Can I turn the security off?

Yes, with `app.security(None)`, but only do it when another layer protects the app. To relax one rule, change the shield instead: `paquets::shield().without("bot_blocker").build()`. See [Security](security.md#changing-the-shield).

## Deployment

### Can I really deploy from a phone?

Yes: the Deploy to Heroku button, the database add-on, the automatic deployments, code changes, logs and custom domains all work from a phone's browser and the GitHub app. Only creating a new project with `paquets new` needs Rust, once, on a computer or in a cloud development environment. See [Deploy to Heroku from your phone](deploy-heroku-mobile.md).

### Does it work on other hosts than Heroku?

Yes: the `Dockerfile` runs on Render, Fly.io, Google Cloud Run, Railway or your own server. Check the client IP setting for your platform. See [Docker](deploy-docker.md#other-platforms).

### Why is the first build so slow?

Rust compiles every dependency once, with every optimisation in release mode, and the first build of a project with islands also installs `wasm-bindgen-cli`. Later builds only recompile your code. On Heroku, the first build often takes 10 to 20 minutes.

## The project

### How do I update Paquets?

In a project: `cargo update -p paquets` (and the four packages come with it). The command line tool: `cargo install --git https://github.com/maxlestage/Paquets paquets --locked --force` (or the same command with `--git`). Read the changelog first: before 1.0, minor versions may change the API.

### How do I report a bug or contribute?

Open an issue on GitHub. Pull requests are welcome; read `CONTRIBUTING.md` first. A bug in one of the four packages is best reported in its own repository (see [The four packages](packages.md)).
